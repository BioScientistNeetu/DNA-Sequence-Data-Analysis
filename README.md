# DNA-Sequence-Data-Analysis
A Python -based DNA sequence analysis project for basic bioinformatics analysis.

## Features

- DNA sequence validation
- DNA sequence length calculation
- Nucleotide counting (A, T, G, C)
- GC content calculation
- AT content calculation
- Complementary DNA sequence
- Reverse DNA sequence
- Reverse complement sequence
- DNA to mRNA transcription
- Codon generation
- Protein translation
- Stop codon identification

## Technologies Used

- Python
- Visual Studio Code
- Basic Bioinformatics Concepts

## How to Run

1. Download or clone this repository.
2. Open the project in Visual Studio Code.
3. Run DNA-Sequence-Analyzer.py.
4. Enter a DNA sequence when prompted.

## Project Purpose

This project was developed to practice Python programming and apply basic bioinformatics concepts to DNA sequence analysis.
